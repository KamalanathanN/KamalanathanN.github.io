Visual Language Action (VLA) Integration for Industrial Manipulation

C++ ROS2 PyTorch LLM

Project Overview

This ongoing research project is being conducted at Drexel University under the supervision of Dr. Lifeng Zhou at Zhou Labs. The research focuses on fine-tuning LLaVA-1.6 for real-time visual-language action planning on a 6-DOF industrial manipulator, with specific applications in industrial processing of vegetables. The integration with ROS 2 behavior trees enables sophisticated autonomous manipulation tasks that can understand both visual cues and natural language instructions for complex food processing operations.

Key Features

  • Real-time visual perception and language understanding
  • Fine-tuned LLaVA-1.6 model for robotics applications
  • ROS 2 behavior tree integration for action planning
  • 6-DOF manipulator control and coordination
  • Multi-modal input processing (vision + language)

Technical Implementation

The system leverages advanced computer vision and natural language processing to enable intuitive human-robot interaction. By integrating visual and linguistic modalities, the robot can understand complex instructions like "pick up the red object next to the blue cup" and execute appropriate actions in real-time. The architecture combines:

  • Custom dataset creation for robotics-specific VLA tasks
  • Fine-tuning pipeline using PyTorch and distributed training
  • ROS 2 nodes for model inference and action execution
  • Behavior tree framework for robust task planning

Results & Impact

As an ongoing research project, preliminary results have demonstrated significant improvements in task completion rates and reduced the need for explicit programming of manipulation tasks for vegetable processing applications. The system has shown robust performance across various scenarios and lighting conditions, achieving:

  • 85% success rate in pick-and-place tasks
  • Real-time inference at 10 Hz
  • Generalization to unseen objects and scenarios
  • Reduced programming time by 60% for new tasks
